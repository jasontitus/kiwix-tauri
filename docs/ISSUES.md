# Desktop issue coverage and acceptance

## What this audit means

The public snapshot contains **100 open issues (PRs excluded)** and **15 issues closed since 2026-07-01**, retrieved during the session with supplied audit date 2026-10-28. Some API timestamps are later; this is a retrieval snapshot, not a historical midnight assertion. Open search reported total_count=100 and incomplete_results=false; independent endpoint pagination reached an empty page. Closed duplicates and upstream blockers are not treated as fixes.

Every open issue below has an implementation reference or explicit absent/nonapplicable/release disposition plus its remaining verification. **No row means verified fixed.** Exact original titles and acceptance analysis are preserved in the [full issue report](audit/desktop-issue-audit.md); the [complete open JSON response](audit/desktop-open-issues.raw.txt) and [15-closed response](audit/desktop-recent-closed-issues.raw.txt) preserve bodies, labels, timestamps and stable genuine issue URLs. The raw responses include their retrieval headers. The two invalid shortened comment fragments in the source report were replaced with stable issue URLs and explicitly annotated; no comment IDs were invented. Full [desktop](audit/desktop-source-audit.md) and [Apple](audit/apple-source-audit.md) reports are also preserved, including their historical artifact/tool limitations. They describe predecessors, not proof of this app.

Current [platform status and remaining work](FEATURES.md#platform-status-and-remaining-work), [package identities](PACKAGING.md) and [changelog evidence](../CHANGELOG.md#verification-and-known-limits) are maintained separately from this issue census. Integrated checking passed 403 Rust tests (two ignored), eight production sensor-bridge regressions and TypeScript, plus a separately executed mobile-admission regression on actual Android and iOS-simulator targets. The Android cold-bootstrap error was reproduced before correction and verified afterward on emulator and physical-phone startup/navigation/Home-resume, preserving settings and the failed transfer. These build-scoped checks do not close every upstream issue: Windows, physical sensors/radio, macOS notification delivery, iOS OS-managed background HTTP semantics, partial translations, clean-machine releases and accessibility retain explicit acceptance gates.

## Integration-owner acceptance priorities

1. Malicious archive: external scripts/forms/meta redirects/iframes, dangerous protocols, foreign origin/Host, service-worker bypass, cross-archive error content, expired sessions, and native accelerator spoofing. The privileged headless shell and archives must never share an origin.
2. Privacy and devices: normal/private/normal and read-only across multiple windows, UUID cookie/localStorage restoration versus transient native storage, stale saves, listener/port reuse, denial/revocation/navigation teardown, OS permission prompts and actual camera/location hardware.
3. Destructive/crash safety: unrelated sentinels, symlink/path swaps, full/read-only/external disks, queued/paused/interrupted/error jobs, HTTP validators, torrent recheck and shutdown, publication/import crash boundaries, StreetZim cache corruption/reuse/cancellation and saved-map restart.
4. Offline reader/search fixtures: Wikipedia, real Zimit video/hash routes, Gutenberg shelves and PDF/EPUB resources, WASM, World map Fetch/WebGL, ToC DOM/history, fragments, mixed scripts and punctuation/date queries, combined search pagination and slow-NAS performance.
5. Actual OS experience: native startup/associations/foreground, Wayland/KDE/Awesome, Windows DPI, all platform screen readers, GNOME on-screen keyboard, print/PDF/speech, and localized RTL/plural/fallback behavior.
6. Release: clean-machine dynamic dependency closure, Windows trusted SDK/WebView2, Linux runtime baseline, macOS deployment target/signing/notarization, versioned artifacts/checksums and authorized publication. No stores/updater/Flatpak/MSIX channel is implied by source configuration.

These priorities remain acceptance gates beyond the specific scenarios above. [LocalSwarm P2](LOCALSWARM.md) is implemented, distinct from BitTorrent and LAN HTTP service, with real cross-device peer evidence and outstanding integration fixes/checks. The complete closed-issue/PR audit is linked above; audit completion does not close its implementation or platform acceptance gaps. Same-host dual-stack LAN authorization/Stop evidence concerns the separate HTTP sharing service and is not cross-device HTTP acceptance.

### Regression guard list (Android-derived)

Each guard is a concrete check a future change can run; the full list with upstream evidence is in the [Android issue audit](audit/android-all-closed-issues.md#regression-guard-list).

1. **Notes:** notes on `A.html`, `A.B.html`, `A%2FB.html`, `A?x=1` in two archives produce 8 distinct rows that survive restart; deleting one removes exactly one.
2. **Bookmarks:** bookmark an article, its redirect alias and the same path in another archive; deleting one id leaves the others and both library entries.
3. **History:** `/A`, `/a`, `/A?q=1` remain three rows after a locale change; missing archives are labelled and not opened.
4. **Encoding:** `+`, `%`, `#`, `?`, spaces and non-ASCII round-trip through search, bookmarks, history, export and reload without blank pages.
5. **Ranges:** `0-0`, `50-`, `-10` and out-of-range requests return correct bytes/status (206/416).
6. **Split ZIM:** `.zimaa` alone and with an extra part are rejected; a complete cohort is one book and a bookmark survives.
7. **Downloads:** pause, kill, restart and resume yields the exact remainder, one published file and a matching SHA-256; no duplicate job.
8. **Reconnect:** after connectivity returns, the documented policy is honoured and staging stays intact.
9. **Library retention:** maintenance on a missing archive flips only `available`; the book row and metadata remain.
10. **Appearance:** dark cold launch has no light flash and image pixels are unchanged.
11. **TOC/find:** collapsed targets are revealed; a no-outline article disables the TOC control; find is scoped to the active tab.
12. **Catalogue:** query/filter/pagination encoding survives spaces, `&`, `+` and non-ASCII; no page is skipped.
13. **Service workers:** `_sw:yes` is disclosed before acquisition and never presented as readable.
14. **Speech:** closing a tab stops speech and a stale capability cannot restart it.
15. **Packaging:** `zipalign -c -P 16` and `llvm-readelf -lW` show ≥0x4000 `LOAD` alignment for every bundled native library.
16. **Import safety:** importing into a directory with a sentinel and a symlink neither clobbers nor escapes.
17. **Stale readers:** deleting/replacing an open archive never serves stale bytes.
18. **Search cancellation:** a cancelled query starts no further snippet work and does not queue the next query behind it.
19. **CJK:** 1-, 2- and 3-character Chinese queries match `zimsearch`/libzim output on a fixture.
20. **Uninstall policy:** the documented outcome for managed copies and external-provider references is observed, and user originals are never deleted.

These guards are regression checks, not evidence that the behaviours were executed. The P1 packaging guard is the only one that can block installation today; the rest protect correctness of already-implemented paths.
