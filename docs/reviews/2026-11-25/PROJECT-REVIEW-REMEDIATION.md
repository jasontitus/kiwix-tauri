## Summary of changes by milestone

### Milestone 1 — Rust core, maintenance, startup, sync & sharing
- **Folder watch & maintenance (`watch.rs`, `lib.rs`, `service/dispatch.rs`):** bounded the `FolderWatch::shutdown` watcher thread join to `DRAIN_LIMIT` (5 s) so a stalled volume cannot hang Quit; desktop `maintenance()` checks `ensure_running()` and `store.read_only()` directly; monitored-folder fallback scans canonicalize known book paths, skip unchanged corrupt files recorded in `watch_failures` (without applying `watch::is_settled` so clock-skewed files still import), and record scan outcomes.
- **Startup CLI opening (`lib.rs`):** moved startup `open_paths` off the Tauri setup thread onto an async task using a synchronously captured `launch_generation`, surfacing failures via `note_startup_warning` and waking `"main"` with `kiwix-open`.
- **Memory & crash metadata (`archive.rs`, `crash.rs`, `service.rs`):** reduced mobile per-archive decoded cluster cache to 8 MiB (`32 MiB` on desktop); added `seed_archive_validation` so persisted validation metadata seeds crash reports without overwriting fresher live validations.
- **Reading-sync fast path (`reading_data.rs`, `reading_data_tests.rs`):** skipped cloning `ReadingSync` and repeating full validation on unrelated normal-mode store mutations when bookmarks match their projection, positions are unchanged, and no newly imported book can enrich a missing `legacy_book` descriptor.
- **Private Sync mobile rebind (`private_sync_service.rs`):** checked `runtime.endpoints().is_ok()` on mobile before reusing a listener and exited the mobile listener loop on the automatic-sync tick when `runtime.endpoints()` fails, retiring any prior runtime/session/activity before rebinding.
- **Sharing performance & shutdown (`sharing.rs`, `sharing_tests.rs`, `sharing_interop_tests.rs`):** added 2 s TTL caching to `SessionHosts`, LRU eviction to `LibraryHosts` per-book HTTP listeners, and `spawn_blocking` offloading for `SharingCancellation::drain_native` during shutdown.

### Milestone 2 — Transfers, imports, torrent storage, LocalSwarm, maps & parallel search
- **Single-stream HTTP retries & hashing (`acquisition/transfer.rs`, `acquisition_tests.rs`):** added bounded transient retries for connect errors (excluding deterministic redirect rejections) and HTTP `429`/`5xx` checked before `CONTENT_ENCODING` (so gzipped CDN error responses retry), resetting `body_retries` once payload bytes stream; moved SHA-256 verification onto `spawn_blocking`.
- **Import verification byte progress (`imports.rs`, `src/types.ts`):** added throttled (250 ms), cancel-guarded, monotonic `verified_bytes` / `verified_total` (`verifiedBytes` / `verifiedTotal`) across single-file and multi-file batches (estimating remaining files minus the 16-byte ZIM checksum trailer) and reset on start/retry.
- **Torrent storage & Windows publication (`torrent/*.rs`, `torrent_tests.rs`):** converted `ConfinedStorage` gates to `RwLock` (`read()` running positional `pread_exact`/`pwrite_all` on a cloned `Arc<File>` outside the `files` mutex; `write()` for init/length/fencing) and added Windows positional `PositionalReader` / `seek_read` in `publication.rs` to eliminate shared `FILE_OBJECT` cursor races during concurrent seeding.
- **Parallel multi-archive search (`search.rs`):** added `rank_initial_parallel` with pre-cancel checks, calling-thread work plus bounded `Builder::new().name("search-rank").spawn_scoped` workers, and deterministic index ordering.
- **LocalSwarm concurrency & cleanup (`localswarm/mod.rs`, `localswarm/cleanup.rs`):** switched `SourceSet::retained` to `RwLock` with positional `EINTR`-safe `read_exact_at`; moved cancellable `SourceSet::prepare` and `start()` network dials outside the `operation` mutex under `sharing_lifetime`, `seed_setup_gate`, and `receive_setup_gate` so `stop()`/`stop_sharing()` still fence setup; added `CleanupDigestCache` keyed by `(swarm_id, index, dev, ino, len, mtime_ns, ctime_ns)` with racy-timestamp separation.
- **Maps telemetry, gzip & recipe cache (`Cargo.toml`, `Cargo.lock`, `maps.rs`, `maps/compose.rs`, `maps/manager.rs`, `maps_tests.rs`, `src/types.ts`):** added throttled `MapJob.speed` and `eta_seconds` (reset across startup/resume/completion/finish/error backoff); added `MAX_JSON`-bounded (32 MiB) gzip inflation in 64 KiB cancellable chunks in `fetch_json` using already-vendored `flate2 1.1.11` (`rust_backend`, 0 new crates, 0 unsafe delta); added `Arc<Recipe>` `RECIPE_CACHE` (max 1 mobile / 2 desktop, 5 min TTL) cleared via `clear_recipe_cache()` on `MapManager::clear_cache()`, `MapManager::cancel()`, `CatalogRegistry::retire()`, `Service::shutdown()`, privacy changes in `save_settings`, and mobile background entry.

### Milestone 3 — Kokoro, iOS storage & maintenance cadence, desktop updater cancel
- **Kokoro lock separation (`kokoro.rs`):** introduced `cache_gate: Arc<Mutex<()>>` (strict lock order `cache_gate` → `state`) so `publish_audio` and `clean_cache` release `state` across WAV `sync_data()` and cache sweeps while `delete()`, `drain_download()`, privacy cutover, and shutdown still fence `cache_gate`.
- **iOS external document concurrency (`DocumentStorage.swift`, `KiwixMobilePlugin.swift`):** added `NSLock` to `ExternalDocuments` protecting `transient`, `selectedURLs`, `leases`, and `defaults` while keeping `coordinatedRead`, SHA-256 `pread`, and bookmark resolution outside the lock (with post-hash revocation recheck); routed `openIncomingArchive` and `.external`/`.externalBatch` picker intake hashing onto a dedicated `hashWorker` (`qos: .utility`) so `providerWorker` interactive leases do not stall.
- **iOS foreground maintenance cadence (`mobile.rs`, `mobile_service.rs`, `service.rs`):** backed off iOS foreground `maintain()` from 1 s to 5 s when completely idle (reconciliation, local transfers, and Live Activity all idle), paired with `transfer_signal_generation` / `transfer_reconciled_generation` counters so newly started work wakes reconciliation promptly without a background spin loop.
- **Desktop update download cancellation (`update.rs`, `service.rs`, `src/components/UpdatesSettings.tsx`):** added `"update_cancel"` handled in `Service::operation` before `privacy_gate` (preventing write-fair deadlock behind pending privacy writers), `ActiveDownloadCancel` with a monotonic token registered before `"downloading"` progress emission, `USER_DOWNLOAD_CANCELLED`, and a localized Cancel button in `UpdatesSettings.tsx` whose `cancelling` state resets on phase change or `false` reply.

### Milestone 4 — Frontend UX, accessibility, performance & reader storage
- **Lazy chunks & reader shell stability (`src/App.tsx`):** lazy-loaded `UnifiedSearch`, `CrashReport`, and `IncomingArchiveDialog`; kept `<ReaderHost>` mounted across tab switches with `<PaneBoundary>` inside `<div key={epoch}>` so tab switches never bypass `retireReaderDocuments`; kept live scroll updates in `liveScrolls` + reference-stable `mergeLiveScrolls(tabs)` cache keyed on `(base, liveScrollVersion)` and cleared on tab/session commits so scrolling does not trigger full-shell re-renders or break `flushSession` / `checkpointTabIndex`.
- **Reader accessibility & pointer selection (`src/components/Reader.tsx`, `src/reader-bridge.js`):** added `Escape` close + focus return on `HistoryDisclosure` (bailing out when `<dialog open>` is present and stopping propagation); deferred `selectionchange` scans during primary-pointer drags (`pointerSelecting`) with mouse `buttons === 0` self-heal and `window`/`document` reset listeners (`pointerup`, `pointercancel`, `mouseup`, `blur`, `visibilitychange`, `contextmenu`, `dragstart`, `dragend`).
- **Android viewport zoom (`src/main.tsx`):** removed the Android `maximum-scale=1.0, user-scalable=no` viewport lock.
- **Reader storage freeze admission (`src/reader-storage.ts`, `scripts/test-reader-storage-admission.mjs`):** skipped registered pre-ready iframes (`!binding.ready`) in `adoptFreeze` instead of stalling for 5 s, while preserving terminal `quarantinedBindings` across `retireReaderStorageGeneration`.

- **Desktop updater buffering:** `tauri-plugin-updater` still buffers the downloaded installer in a `Vec<u8>` (`download` / `install(&[u8])`); streaming to disk remains an upstream plugin API limit.
